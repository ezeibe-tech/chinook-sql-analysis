# Chinook SQL Analysis

## Project Overview
This project demonstrates SQL analysis using the Chinook sample database in PostgreSQL. It includes data retrieval, filtering, aggregation, joins, window functions, and business analysis queries.

## Objectives
- Analyze customer purchasing behavior
- Calculate total revenue and average invoice values
- Identify top customers
- Analyze revenue by country and genre
- Identify top-selling tracks

## Database
- Chinook Sample Database

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## SQL Concepts Demonstrated
- SELECT
- WHERE
- ORDER BY
- LIMIT
- DISTINCT
- GROUP BY
- HAVING
- INNER JOIN
- Aggregate Functions
- Window Functions

## Project Files
- `chinook_db_sql.sql` – Complete SQL queries used for the analysis.
